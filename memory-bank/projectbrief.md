# Project brief

Native **Jetpack Compose** Android customer app for Durpalla (`com.durpalla.booking`), porting Flutter **master** `@8ee2bed` (not Flutter `main`).

**Goals**
- Parity with Flutter master for auth, transport booking, hotels, tours/events, boat rental, payments, tickets, l10n, push, Pusher seat locks.
- In-app **driver calling** (WebRTC + Firestore) matching `Durpalla/durpalla-driver` `docs/calling-contract.md`.

**Out of scope here:** iOS, driver app, backend changes, Flutter codebase edits.

**Primary refs:** `README.md`, `API_MAP.md`, `MASTER_PORT_TODOS.md`, `docs/calling-contract.md`, this `memory-bank/`.
